# Sonali Homes LLP

![Sonali Homes Logo](./sonali-homes-logo.png)

This is the official website for Sonali Homes LLP, a real estate company specializing in the sale of residential flats. This website provides clients with information about the company, its ongoing and completed projects, and ways to contact us.

## ✨ Features

*   **Home Page:** An introduction to Sonali Homes LLP.
*   **About Us:** Information about the company's mission and vision.
*   **Projects:** A gallery of current and upcoming real estate projects.
*   **Project Details:** Dedicated pages for each project with detailed information, like for "Mahadev Heights".
*   **Contact Form:** A simple way for potential clients to get in touch.
*   **Responsive Design:** The website is designed to work on various devices.

## 🛠️ Technologies Used

This is a static website built with fundamental web technologies:

*   **HTML5:** For the structure and content of the web pages.
*   **CSS3:** For styling and layout.
*   **JavaScript:** For interactive elements and functionality.

## 📄 Pages

The website consists of the following pages:

*   `index.html`: Home Page
*   `about.html`: About Us Page
*   `projects.html`: All Projects Page
*   `mahadev-heights.html`: Details for the Mahadev Heights project.
*   `contact.html`: Contact Information and Form.
*   `privacy-policy.html`: Privacy Policy.

## 🚀 How to Run the Project

No complex setup is required. To view the website:

1.  Clone or download this repository.
2.  Open the `index.html` file in your preferred web browser (like Chrome, Firefox, or Edge).

That's it! You can now navigate through the entire website.
